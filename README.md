# Fraudulent Transactions Detection for a Financial Company<br><br>
- This project aims to detect fraudulent transactions using a financial dataset named "Fraud" with a shape of (6,362,620 rows × 11 columns). The project begins with data analysis and feature engineering, followed by the use of various charts to explore and visualize patterns in fraudulent behavior.
- After understanding the data through Exploratory Data Analysis (EDA), a machine learning model is built using the XGBoost classifier. The model’s performance is evaluated using a classification report to assess its effectiveness in identifying fraud.
The project mainly highlights:
- Patterns and Trends observed in fraudulent activities (such as transaction type, amount, and balance anomalies).

- Preventive Measures the company should adopt when updating its infrastructure to reduce fraud risk.

- This analysis helps the company gain insights into fraud behavior and build a proactive fraud detection system.
